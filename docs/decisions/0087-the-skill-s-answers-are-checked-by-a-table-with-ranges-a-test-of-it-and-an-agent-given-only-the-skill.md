# 0087. The skill's answers are checked by a table of answers with ranges, a test of it, and an agent given only the skill

- **Status:** Proposed
- **Date:** 2026-11-12

- `skills/human-o-matic/references/vocabulary.md` holds two tables, `Answers` and `Refinements`, a row per answer: the answer in double quotes, a column each for `energy`, `groove`, `dynamic_range`, `tightness`, `feel` and `ghost_level`, and `Also` for `fill_intensity`, `arc`, `skip` and `set_style`'s `style`, as `name: value` entries separated by `; `. A number is a starting point and its range, `0.95 [0.85, 1]`, the values that still read the answer the same way, and a blank cell a control the answer leaves unset. A refinement's numbers are changes to a control's current value.
- `tools/check_answers.py` reads the tables and checks every row: each name a control or `style`, each value one the control model or the built-in styles take, each point in its range, and each range in its control's, a refinement's from the style's defaults. A test reads the shipped tables: at least 30 answers, the plan's four examples first at its values, and every row valid. Another holds the skill's frontmatter to a Claude Code skill's, and its text to naming every tool the server serves.
- The agent pass: `check_answers.py` words each answer of the tables as a user might, a phrase per answer, kept in the tool and apart from the tables. `phrases` prints them alone, and `brief` after what the agent is asked. An agent given only `SKILL.md` and the vocabulary gives the controls it would set for each, for a section whose own controls and the song's are unset, as a JSON object from each phrase to its controls. `compare` checks them, clamped as the server clamps them, with those left out at the style's defaults: each control the answer's row gives must lie in its range, and each it leaves out stay at its default. It prints each miss and how many answers read as the vocabulary means them, and exits 1 on a miss.
- The live check, a real song through a Claude Code session with the server registered and the skill installed, is the plan's end-to-end step and follows the agent pass.

**Why:** A table a test parses keeps the vocabulary valid as the controls change. An agent with only the skill shows whether the skill and its vocabulary alone turn answers into the intended controls, and phrases worded apart from the table make it find the row an answer means, as it must with a real user's words, rather than read the row beside it.

**Consequences:** The pass compares controls, not sound: whether a range sounds as its answer means is the owner's to hear. It reads no section's facts, so the thresholds of [ADR 0082](0082-a-section-s-facts-are-counted-and-its-guess-says-only-what-the-score-shows.md) meet a real song first in the end-to-end session.
