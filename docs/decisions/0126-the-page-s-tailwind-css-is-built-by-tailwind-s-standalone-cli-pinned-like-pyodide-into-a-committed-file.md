# 0126. The page's Tailwind CSS is built by Tailwind's standalone CLI, pinned like Pyodide, into a committed file

- **Status:** Proposed
- **Date:** 2026-11-15

- **The committed file:** the page's CSS is `web/static/tailwind.css`, committed, which the site's build copies as it is with the page's other files. The page loads it in place of Tailwind's Play CDN, which it no longer loads, and runs no Tailwind script.
- **How it is rebuilt:** `uv run python tools/build_site.py css` runs Tailwind's standalone CLI, minified, over `web/tailwind/input.css`, the owner's design's style block and the styles of what the page's scripts draw, then Tailwind's base, components and utilities, in the order the page had them from the Play CDN, and `web/tailwind/tailwind.config.js`, the design's palette and fonts, whose content is `index.html` and `js/*.js`. Neither file ships. A class must be written whole in those files, never put together from parts, for the CLI to keep it. The file is rebuilt after a change to either file or to a class of the page's.
- **The CLI, pinned like Pyodide:** the release binary for macOS on Apple silicon, at 3.4.17, the Play CDN's version the owner saw, by URL and SHA-256 in `tools/build_site.toml`, downloaded into `build/site-downloads/` and refused if its SHA-256 differs ([ADR 0115](0115-the-site-downloads-pyodide-s-core-release-its-numpy-and-pypi-s-wheels-at-uv-lock-s-versions.md)). GitHub gives no digest for this asset, so the pinned SHA-256 is of the file downloaded, whose size is the release's. No Node and no npm package: the CLI is one binary.
- **The CSP narrowed back:** `script-src` loses Tailwind's CDN and `style-src` loses `'unsafe-inline'`, which nothing needs any more. The page has no style attribute and no style element of its own, and its code sets no style.
- **What stays third-party:** Google Fonts' stylesheet and fonts, with their two origins in `style-src` and `font-src`, and the visitor's IP address reaching Google on a visit.
- A test runs the CLI, when it is in `build/site-downloads/`, and holds its output to the committed file byte for byte; without the CLI, as on CI's Linux, it is skipped and says why.

**Why:** The owner chose to commit the built file. The page then runs no third-party script, the CSP allows no inline style again, and the CSS is the page's own to count and test, while the design keeps the classes the owner saw.

**Consequences:** [ADR 0125](0125-the-page-takes-the-owner-s-design-in-tailwind-from-its-play-cdn-with-google-fonts-the-mascot-as-its-logo-and-a-loading-view.md)'s Play CDN, its integrity hash, its configuration file of the page's own and its CSP are amended by this ADR, as are [ADR 0118](0118-the-page-is-hand-rolled-es-modules-with-native-controls-and-no-library.md)'s line that the page uses no library, now Tailwind's built CSS alone, and [ADR 0119](0119-the-build-writes-netlify-s-headers-with-hsts-for-a-year-and-fails-on-a-file-of-10-mb-or-more.md)'s CSP. The CSS is rebuilt only on macOS on Apple silicon until another platform's binary is pinned beside it, and forgetting to rebuild leaves a new class without its CSS until the byte-for-byte test, where the CLI is present, catches it. The CLI warns that its browser data is old, which sets only which vendor prefixes it writes. The file measured 29,809 bytes, 6,841 compressed, and the page's own files 46,514 bytes compressed in all.
